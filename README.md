# NewHistory 6
Сборка просто для друзей

## Апдейтер v14.2

При каждом обычном запуске апдейтер сначала скачивает и проверяет `Updater.ps1`, `Updater.bat` и `Check.bat` с GitHub. Если на GitHub версия новее, он проверяет синтаксис PowerShell и совпадение версий трёх файлов, сохраняет резервные копии, устанавливает комплект, закрывает старое окно и запускает новую версию. После этого открывается меню обновления сборки. Если проверить или обновить апдейтер не удалось, обновление модов не запускается. Старые копии апдейтера и bootstrap-файл удаляются при старте.

Обновление сборки сохраняет миры, папки Xaero и QuickSkin: корень копируется без зеркального удаления, а `/MIR` применяется только к `mods`, `tacz` и `kubejs`. Устаревшие JAR, включая AoA3, удаляются из активной папки `mods`; сторонние JAR сохраняются отдельно в `mods-local-backup-*` и не загружаются игрой. Пункт «Скачать остальные моды» использует такую же синхронизацию, поэтому не оставляет старые версии модов.

В сборке используется единый комплект: `Updater.bat`, `Updater.ps1` и `Check.bat`. На версиях v14.0 и новее комплект обновляется автоматически при обычном запуске `Updater.bat`. Для более старой версии один раз замени эти три файла версиями из GitHub.

Проверка версии сборки сохранена: сначала читается последний commit через GitHub API, при ошибке используется `version.txt` из raw GitHub. Загрузка проверяет HTTP-ответ и не продолжает распаковку при пустом или ошибочном ответе.
