# NewHistory-v3
Сборка просто для друзей

## Апдейтер v13.0

При обновлении `Updater.ps1` сохраняет пользовательские миры, папки Xaero и QuickSkin: корень обновляется без зеркального удаления, а `/MIR` применяется только к `mods`, `tacz` и `kubejs`.

### Если установлен старый апдейтер v12.x

Скопируй `Updater-v13-bootstrap.bat` в папку сборки рядом с `Updater.bat` и запусти его один раз. Он скачает и проверит новый `Updater.ps1`, сохранит копию старого файла и запустит штатный апдейтер. После этого обновляй сборку обычным `Updater.bat`.

Проверка версии сохранена: сначала читается последний commit GitHub API, затем при ошибке используется `version.txt` из raw GitHub. Сообщение коммита релиза должно содержать номер вида `v13.0`.
