Сборка просто для друзей

## Апдейтер v14.1

При каждом обычном запуске апдейтер сначала скачивает и проверяет единственный актуальный `Updater.ps1` с GitHub. Если на GitHub версия новее, он сохраняет резервную копию, устанавливает её, закрывает старое окно и запускает новую версию. После этого открывается меню обновления сборки. Если проверить или обновить апдейтер не удалось, обновление модов не запускается. Старые копии апдейтера и bootstrap-файл удаляются при старте.

Обновление сборки сохраняет миры, папки Xaero и QuickSkin: корень копируется без зеркального удаления, а `/MIR` применяется только к `mods`, `tacz` и `kubejs`.

В сборке используется один актуальный комплект запуска: `Updater.bat` и `Updater.ps1`. На версиях v14.0 и новее обновление апдейтера происходит автоматически. Если установлена более старая версия, один раз замени эти два файла версиями из GitHub, после чего проверка будет автоматической.

Проверка версии сборки сохранена: сначала читается последний commit через GitHub API, при ошибке используется `version.txt` из raw GitHub.
