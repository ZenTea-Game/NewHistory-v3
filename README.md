Сборка просто для друзей

## Апдейтер v14.0

При каждом обычном запуске апдейтер сначала скачивает и проверяет файл `Updater.ps1` с GitHub. Если на GitHub версия новее, он сохраняет резервную копию, устанавливает её, закрывает старое окно и запускает новую версию. После этого открывается меню обновления сборки. Если проверить или обновить апдейтер не удалось, обновление модов не запускается.

Обновление сборки сохраняет миры, папки Xaero и QuickSkin: корень копируется без зеркального удаления, а `/MIR` применяется только к `mods`, `tacz` и `kubejs`.

AoA3 больше не входит в сборку и не скачивается апдейтером. В апдейтере v13 ещё нет автоматической самопроверки, поэтому при переходе с v13.0 или старше запусти `Updater-v13-bootstrap.bat` один раз. Начиная с v14.0 апдейтер обновляется автоматически.

Проверка версии сборки сохранена: сначала читается последний commit через GitHub API, при ошибке используется `version.txt` из raw GitHub.
